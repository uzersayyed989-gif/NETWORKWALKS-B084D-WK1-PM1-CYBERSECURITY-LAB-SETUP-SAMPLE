## 📌 Project Overview

This practical focuses on setting up a basic Cybersecurity Lab using Kali Linux in Oracle VirtualBox.

The main objective is to configure the virtual machine, understand network settings, identify IP addresses, configure DNS, and verify network connectivity.

## 🎯 Objectives

- Install and configure Kali Linux in VirtualBox.
- Set up the virtual machine network adapter.
- Identify the system's IP address.
- Understand network interfaces.
- Configure and verify DNS settings.
- Check the default gateway.
- Test internet connectivity.
- Understand basic Linux networking commands.

## 💻 Linux Commands Practiced

| Command | Purpose |
|---|---|
| `ip a` | Display IP addresses |
| `ip addr show` | Show network interfaces and IPs |
| `ip route` | Display routing table |
| `ip link` | Check network interfaces |
| `ping 8.8.8.8` | Test internet connectivity |
| `ping google.com` | Test DNS resolution and connectivity |
| `cat /etc/resolv.conf` | View DNS configuration |
| `nmcli device status` | Check network device status |
| `nmcli connection show` | Display network connections |
| `hostname -I` | Display system IP addresses |
